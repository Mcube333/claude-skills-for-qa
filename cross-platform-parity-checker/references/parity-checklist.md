# Parity checklist

## Content
- Headings, labels, button text, helper text, tooltips, disclaimers (exact wording, case, punctuation)
- Placeholder and empty-state text
- Error and validation messages

## Numbers and formatting
- Amounts and totals (do they add up on each platform?)
- Currency symbol and position, thousand separators, decimal places, rounding
- Units (per month, /mo, monthly), date and time formats, plurals ("1 items")
- Strike-through original price vs discounted price, percentage formats

## Structure and order
- Sections present / missing / extra
- Row order inside a section
- Collapsed vs expanded by default
- Number of items shown before "View more"

## States
- Loading, empty, error, offline, disabled, sold out / out of stock
- Logged-in vs guest, new vs returning user, experiment variant
- Long text, long names, many items, zero values

## Interaction
- Tap/click targets and what they open
- Tooltip trigger (tap vs hover) and dismissal
- Back navigation, scroll position, sticky elements
- Keyboard type for inputs, input masks

## Visual design
- Colours (especially semantic: discount green, error red), font size and weight
- Spacing, alignment, dividers, icon style and size
- Images and aspect ratios

## Accessibility
- Screen reader labels on icons and buttons
- Contrast on small or coloured text
- Touch target size
