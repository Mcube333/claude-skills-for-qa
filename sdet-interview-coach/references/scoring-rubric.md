# Scoring rubric (0-5)

| Score | Technical answer | Behavioural answer |
|---|---|---|
| 5 | Correct, structured, explains why and trade-offs, concrete example from own work, anticipates follow-up | Clear STAR, own actions ("I"), measurable result, reflection/learning, under 2 minutes |
| 4 | Correct and clear with an example; misses one nuance or trade-off | STAR complete, result present but not quantified, or slightly long |
| 3 | Mostly correct but generic (textbook), no example, or one notable gap | Story has the situation and actions, weak or missing result |
| 2 | Partly correct, confused terms, or answers a different question | Vague, mostly "we", no clear outcome |
| 1 | Mostly incorrect, or only buzzwords | Rambling, no real example |
| 0 | No answer / "I don't know" without reasoning | No answer |

Listen-for points by topic: correctness, the "why", a real example, trade-offs, how it was verified,
and clarity (answer first, then detail).

Giving "I don't know, but here is how I would find out" with good reasoning can score 2-3: reward honesty and approach.

## Level calibration

The same answer scores differently by level. Adjust what "5" means:

| Level | A 5/5 answer must include |
|---|---|
| L0 | Correct definition in own words + a simple example |
| L1 | Correct, practical, with an example from their own scripts |
| L2 | The "why", a real example, and one trade-off or failure mode |
| L3 | Trade-offs between options, how it was measured, how it scales, what went wrong |
| L4 | Business impact, people/process aspects, metrics, decision-making under constraints |

A textbook-correct answer with no example is at most 3/5 from L2 upwards.
